# FrontEnd App - Ingeniería Web

Aplicación web cliente desarrollada con React 19, Vite, TypeScript y TailwindCSS.

## 🚀 Características
- Autenticación (Formularios de Inicio de Sesión y Registro con validación).
- Panel de Administración interactivo con Badges de estado e interfaces adaptativas.
- Componentes UI modulares reutilizables (`Button`, `InputField`, `PasswordInput`, etc.).
- Configuración de estilos optimizada con TailwindCSS y Lucide Icons.

## 📦 Instalación y Uso

```bash
# Instalar dependencias
npm install

# Iniciar en modo desarrollo
npm run dev

# Compilar para producción
npm run build
```
